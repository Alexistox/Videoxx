Naming rules:
- Files are camelCase.js (e.g. speechSetup.js, youtubeSync.js); folders are lowercase camelCase single words where possible (studio/import, agent/tools).
- One original rollup module per file: a module boundary is wherever a $N-suffixed name repeats (cache, cache$1, cache$2 => three files), a topic change, or a new block of module state. Drop the $N suffix inside each file.
- Exported names keep their bundle base names (no $N); private helpers stay unexported.
- Per-module duplicated helpers (readJson$N, writeJson$N, clip$N, slugOf$N, readPj$N) stay local to their file unless identical, then move to core/.
- Rollup interop prologue (__create, __toESM, ...) is dropped; use plain ESM imports of electron/node built-ins.
- No barrel files except ipc/index.js (registerAllIpc) and folder-level index.js only when the folder exposes a single public API.
