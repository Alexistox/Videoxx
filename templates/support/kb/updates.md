# Updates and versions
keywords: update, updates, new version, upgrade app, check now, check for updates, restart now, restart to install, update ready, update available, download update, beta, get beta versions, version, which version, what version, changelog, what's new, update not showing, update stuck, old version, automatic updates are off, applications folder, update engine
platforms: both

Videoxx checks for new versions by itself, shortly after it starts and every few hours. Your projects and settings are kept.

## On Windows

1. New versions download in the background. **Settings > General > Updates** shows "Downloading … %".
2. When it is ready, the sidebar shows **Update … ready** ("Restart to install, or it installs on close").
3. Click it (or **Restart now** in Settings) to install right away, or just close the app: it installs then.

## On Mac

1. When a new version is out, the sidebar shows **Update … available** ("Download, then drag it into Applications").
2. Click it (or **Download** in Settings). The download opens in your browser.
3. Open it and drag Videoxx into Applications, replacing the old one.

## Check by hand

**Settings > General > Updates > Check now**. It answers "You're up to date (…)" or says what it found. Your version is shown below: "You have Videoxx …". The same version is in **Settings > General > Workspace**.

## Problems

- "Automatic updates are off: not an installed copy.": this copy can't update itself. On Mac, move the app into the Applications folder and open it from there. On Windows, install it with the installer.
- "Could not reach the update server (offline?).": check your internet, then **Check now**.
- Release notes: when an update is ready, Settings shows what's new under the status line.

## Beta versions

Turn on **Get beta versions** to try new features before everyone else. Betas are tested but may have rough edges.

## "Update engine" in a project

An older project may offer **Update engine** in the editor (also in its Graphics panel). It brings that video up to the newest features; your scenes and settings stay.
